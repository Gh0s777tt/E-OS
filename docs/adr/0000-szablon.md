# ADR-0000 — Tytuł decyzji

- **Status:** Proponowany
- **Data:** RRRR-MM-DD
- **Dowód:** `U-NNN`, `R-NNN`, plik:linia — cokolwiek, co czytelnik może sprawdzić

## Kontekst

Jaki problem wymusił decyzję. Fakty, nie opinie — z liczbami, jeśli je zmierzono.

## Decyzja

Co postanowiono, w trybie oznajmującym.

## Odrzucone warianty

Co jeszcze rozważano i **dlaczego odpadło**. To najczęściej najcenniejsza część.

## Konsekwencje

Co staje się łatwiejsze, co trudniejsze, jaki dług powstaje i kiedy go spłacić.
