## 1. Pytania zadane wprost — odpowiedzi

### 1.1 Czy README nadal mówi o `redox-live.iso`?

**NIE — i nigdy nie mówiło.** `git show <gałąź>:README.md | grep -n "redox-live\|\.iso"` →
**zero trafień** na obu gałęziach. Jedyne nazwy artefaktów w README to `harddrive.img`
(linie 241–242), a te są **poprawne**.

Dryf jest **odwrotny do spodziewanego**: po `50d2c2c2e` cel `make live` produkuje
`eos-$(EOS_VERSION)-$(ARCH)-installer.img` (`mk/config.mk:194-195`), doszedł cel
`make print-installer-medium` (`Makefile:14-15`) i istnieje `docs/install.md` — a **README
nie wspomina o nośniku instalacyjnym ani razu**. Czytelnik README nie dowie się, że E-OS ma
nośnik instalacyjny, jak się nazywa ani jak go zapisać. Szczegóły: wiersz `R-611a` w §2.

**NIE. Twierdzenie jest nieprawdziwe — audyt 02 §8 ma rację.**
